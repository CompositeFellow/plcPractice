## Problem
Design a program to manually turn on and off the three lamps of a stoplight, with interlocking. Pressing pushbutton (PB1) turns on a lamp (GREEN). Pressing pushbutton (PB2) turns on a lamp (YELLOW). Pressing pushbutton (PB1) turns on a lamp (RED). No two lamps can be energized at the same time. Once one lamp is energized, it should prevent other lamps from being energized at the same time.
