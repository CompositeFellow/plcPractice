## Problem
Design a program to control a garage door. Pressing normally-open pushbutton (OPEN) energizes the motor contactor (FWD) until the door reaches normally-open limit switch (UP), releasing the pushbutton (OPEN) stops the operation. Pressing normally-open pushbutton (CLOSE) energizes the motor contactor (REV) until the door reaches normally-open limit switch (DOWN), releasing the pushbutton (CLOSE) stops the operation
